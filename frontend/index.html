Оформление приложения

Переключай стиль для всех игроков. Настройка сохранится на сервере и автоматически применится в открытых приложениях.

✨ Сейчас используется обычное оформление GiftCase.

Halloween: чёрно-фиолетовый фон, тыквенно-оранжевые акценты и сезонный баннер. Повторное нажатие вернёт обычную тему.

Награды игроку

Введи Telegram ID. Можно начислить баланс, выдать подарок отдельно или сделать оба действия одновременно. Если игрок ещё не открывал Mini App, его запись будет создана автоматически.

Создать кейс

Создай кейс, выбери обложку и задай цену. Новый кейс появится для игроков после добавления подарков и включения переключателя «Кейс активен».

Настройки кейса

Шансы вводятся в процентах. Если сумма не равна 100%, backend нормализует значения пропорционально. Количество — ограниченный запас этого предмета; оставь пустым для бесконечного запаса.

Один путь из 30 узлов заменяет адвент-календарь и Halloween Pass. Награды открываются за XP; платной Premium-ветки нет.

⏳ Глобальный таймер

🎁 Редактор наград карты

🧩 Редактор квестов

Выбирай квест для изменения или заполни поля для нового. Прогресс игроков при редактировании сохраняется.

💥 Admin Abuse · раздача всем

Одно действие для всех зарегистрированных игроков. Можно выдать всем выбранный подарок, начислить внутренние кредиты каждому или сделать оба действия. Перед отправкой будет подтверждение.

⏳ Магазин ограниченных предложений

Создавай временные наборы. Укажи период, общий лимит, лимит на одного игрока и награду: подарок, внутренние кредиты или оба варианта. Цена списывается с внутреннего баланса ★.
